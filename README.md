# KB Design Studio website

Modern responsive website redesign for KB Design Studio, including:

- Bespoke interiors, kitchens, bedrooms and cabinetry homepage
- Responsive project gallery
- Journal/blog landing page
- SEO-focused kitchen cabinet maintenance article
- SEO-focused modern kitchen design trends article
- About and contact pages
- Original KB Design Studio image assets referenced from the existing website

## Pages

`index.html` · `about.html` · `gallery.html` · `blog.html` · `blog-maintain-kitchen-cabinets.html` · `blog-modern-kitchen-style-trends.html` · `contact.html`

The design is responsive and uses Google Fonts plus the existing KB Design Studio image URLs.
